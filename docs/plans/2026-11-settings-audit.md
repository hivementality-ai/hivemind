# Settings and integrations audit (plan item 4.1)

Date: 2026-11-04. Method: read `config/routes.rb`, the controllers and the views. Nothing was clicked in a browser, so rows describe what the code renders. Judged from the side of a non-technical person who uses Claude through a subscription, runs research and work projects, and may have a model server on the LAN.

Severity: **broken** = does not do what it says, or cannot be reached. **confusing** = works, but she would stall or guess wrong. **stale** = out of date, orphaned, or aimed at someone else.

Sidebar: everything below lives in one collapsed "Configuration" group of 13 flat links (`app/views/layouts/application.html.erb:186-300`): Providers, Integrations, Remote Access, APIs, API Tokens, Channels, Webhooks, Templates, Budgets, Knowledge, Approvals, Migration, Audit Log. "Integrations", "APIs" and "Channels" overlap in name; nothing says which one to open first.

## Ranked fix PRs

Each is one builder, small, and independent unless noted. Rank is by how likely it is to stop or mislead her.

1. **Remove the cents budget fields from the agent form** (shipped in this PR, row 1).
2. **Agent page budget bar reads the real budget.** In `app/views/agents/show.html.erb:65-75` use the agent's daily `AgentBudget` (`limit_cents`) as `dashboard_controller.rb:148-157` does; spec with and without a budget row; hide the bar when there is none. Then drop `daily_budget_limit` use from the view.
3. **Claude subscription steps on provider add/edit.** Copy the `claude setup-token` block from `app/views/setup/provider.html.erb:44-56` into `providers/new.html.erb` (anthropic hint at line 241) and `providers/edit_form.html.erb`; reword the "may be restricted" sentence. Request spec asserts the text on `/providers/new`.
4. **LAN model server field up front.** In `providers/new.html.erb:105-125` and `providers/edit_form.html.erb:88-130` open the Advanced `<details>` for ollama/openai_compatible, relabel "Address of your model server", keep the host.docker.internal default as the placeholder. Spec on the rendered `open` attribute.
5. **MCP servers card on Integrations.** Add a card in `integrations/index.html.erb` using `@mcp_presets` and the existing routes (`config/routes.rb:315-321`): name, enabled toggle (`toggle_mcp_server_path`), Connect. Request spec that the page lists a preset. If 4.3 decides to drop MCP, delete the seven controller actions and routes instead.
6. **Google Workspace instructions.** In `integrations/index.html.erb:249-257` add the OAuth consent screen and "add yourself as a test user" steps; rename the "Save & Connect" button (`:277`) to "Save credentials"; show a warning when `request.base_url` is not https or localhost. Spec on the view text via `GET /integrations`.
7. **Agent template search.** `q` param in `agent_templates_controller.rb:7-12`, a scope on `AgentTemplate` matching name/role/description, a search box in `agent_templates/index.html.erb`, and default to featured when no filter. Overlaps 4.2; do it there if that PR is first.
8. **Advanced nav group.** Move APIs, API Tokens, Webhooks, Migration into a second collapsed "Advanced" group in `layouts/application.html.erb`, and add a "Health" link to `/platform/status` and `/platform/doctor` (plus dark-theme classes in `platform/doctor.html.erb`). Request spec that nav contains the links.
9. **Cloud Storage plain-words pass.** Collapse the card behind "Advanced", drop "via rclone" from the subtitle (`integrations/index.html.erb:648`), and warn that the Google Drive token step needs a terminal. Do not change the service.
10. **Replace `alert()` test results with inline text** in the Integrations page scripts (nine call sites), and unify the platform list used by `channels/index.html.erb:66-69`, `integrations/index.html.erb:539` and the channel form select (`_form.html.erb:30`).
