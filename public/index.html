Capabilities

Everything you need for AI teams.

From single-agent chat to multi-agent orchestration with real-time collaboration.

Agent Teams

Group agents into teams with shared context. Agents collaborate via @mentions in team chat, delegating and building on each other's work.

Team Chat

Real-time group conversations. @mention agents to pull them in, or @team to get everyone's take. Agents can chain-react to each other.

Self-Hosted & Secure

Everything runs on your infrastructure. API keys never leave your network. Vault-encrypted secrets, audit logging, and sandboxed execution.

5-Platform Messaging

Connect Discord, Slack, Telegram, WhatsApp, and Signal. Inbound webhooks route messages to the right agents automatically.

24 Built-in Tools

Shell, file ops, web search, browser automation, cron, TTS, Gmail, cloud storage, vision — agents come equipped out of the box.

Sub-Agent Orchestration

Three tiers of collaboration: synchronous delegation, async sub-agents, and conversational team chat. Agents pick the right mode.

Analytics & Budgets

Track token usage, cost, and performance per agent. Set spending limits with real-time budget enforcement.

Multi-Provider

Run Anthropic Claude, OpenAI GPT, or local Ollama models. Mix and match per agent — use the right model for each job.

Autonomous Heartbeat

A hidden system agent that runs on schedule — checking email, calendar, notifications. Agents write tasks to its checklist.

git clone https://github.com/MatthewSuttles/hivemind
cd hivemind
cp .env.example .env

# Launch the full stack
docker compose up -d

# Setup wizard handles the rest
→ Hivemind is running.
