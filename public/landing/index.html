Rails 8 · PostgreSQL · Redis · Sidekiq · Docker · ActionCable

Everything you need to run AI teams

Not just a chatbot. A full platform for deploying, managing, and orchestrating multiple AI agents that work together.

Agent Teams

Create specialized agents with different models, roles, and instructions. Group them into teams that collaborate naturally.

Team Chat

@mention agents in group chat. They respond, collaborate, and chain-react — @mentioning each other when they need help.

24 Built-in Tools

Shell, file ops, web search, browser, cloud storage, Gmail, TTS, vision, cron jobs, messaging — agents can do real work.

5 Messaging Channels

Connect Discord, Slack, Telegram, WhatsApp, and Signal. Agents respond to messages from any platform automatically.

Autonomous Heartbeat

A system agent runs periodic checks — email, calendar, health monitoring. Agents add tasks to a shared checklist.

Vault-Encrypted Secrets

API keys and credentials stored with ActiveRecord Encryption. Per-platform webhook signature verification. Audit logging.

Production-ready architecture

7-container Docker Compose stack. Everything you need, nothing you don't.

R

Rails 8 + Puma

Mission Control dashboard, API, WebSocket streaming via ActionCable

S

Sidekiq

Background jobs — agent execution, tool loops, heartbeat, cron tasks

P

PostgreSQL + pgvector

29 tables, JSONB transcripts, vector embeddings for memory search

B

Playwright Browser

Headless Chromium for web scraping and screenshot tools

C

Connector Sidecar

Node.js bridge for messaging platforms — WhatsApp via Baileys, extensible

Ready to deploy your hive?

Clone the repo, run docker compose up, and you're live in under 5 minutes.

$ git clone https://github.com/MatthewSuttles/hivemind.git
$ cd hivemind
$ cp .env.example .env
$ docker compose up -d
# Open localhost:3001 → setup wizard guides you through the rest
